# সহজ হিসাব খাতা / ব্যক্তিগত ও ব্যবসায়িক (Smart Ledger & Press Manager)

দৈনিক, মাসিক ও বাৎসরিক আয়-ব্যয়ের স্বয়ংক্রিয় হিসাব, প্রেস ও ব্যবসা খাতা, মালের অর্ডার ডেলিভারি ট্র্যাকিং, কাস্টমার বকেয়া ও মহাজন দেনা খাতা, ক্যাশ ড্রয়ার নোট গণক এবং জিমেইল ক্লাউড ব্যাকআপ।

## 📁 ফাইল পরিচিতি (File Structure)

| ফাইল | বিবরণ |
| :--- | :--- |
| **`index.html`** | অ্যাপ্লিকেশনের মূল এন্ট্রি পয়েন্ট এবং এইচটিএমএল কাঠামো। |
| **`script.js`** | অ্যাপ্লিকেশনের সম্পূর্ণ আধুনিক জাভাস্ক্রিপ্ট/রিঅ্যাক্ট কোড (ব্যক্তিগত খাতা, প্রেস খাতা, মালের অর্ডার, কাস্টমার বকেয়া, অডিট হিসাব, ক্যালকুলেটর ইত্যাদি)। |
| **`style.css`** | টেইলউইন্ড ও কাস্টম সিএসএস স্টাইলিং। |
| **`vite.config.ts`** | Vite বিল্ডার কনফিগারেশন (`base: './'` সহ, যা ওয়েব ও অ্যান্ড্রয়েড WebView উভয়ের জন্য পারফেক্ট)। |
| **`package.json`** | প্রজেক্টের ডিপেন্ডেন্সি ও বিল্ড স্ক্রিপ্টস (`npm run build`, `npm run dev`)। |
| **`metadata.json`** | অ্যাপের মেটাডাটা ও প্ল্যাটফর্ম কনফিগারেশন। |
| **`.env.example`** | প্রয়োজনীয় এনভায়রনমেন্ট ভেরিয়েবল ডকুমেন্টেশন। |
| **`firebase-applet-config.json`** | ফায়ারবেস ক্লাউড স্টোরেজ ও অথ কনফিগারেশন। |
| **`firestore.rules`** | ক্লাউড ডাটাবেজ সিকিউরিটি রুলস। |
| **`tsconfig.json`** | টাইপস্ক্রিপ্ট টাইপ চেকিং কনফিগারেশন। |

## 🚀 কীভাবে বিল্ড করবেন (Build for Web & APK)

### ১. ডিপেন্ডেন্সি ইনস্টল ও লোকাল প্রিভিউ:
```bash
npm install
npm run dev
```
ব্রাউজারে `http://localhost:3000` এ অ্যাপটি চলবে।

### ২. প্রোডাকশন বিল্ড তৈরি (`dist/` ফোল্ডার):
```bash
npm run build
```
এটি চালানোর সাথে সাথে প্রজেক্টের সমস্ত আপডেট ফিচার স্বয়ংক্রিয়ভাবে কম্পাইল হয়ে `dist/` ফোল্ডারে চলে যাবে।

## 📱 অ্যান্ড্রয়েড অ্যাপ (APK) তৈরি করার নিয়ম

### পদ্ধতি ১: `dist` ফোল্ডার দিয়ে (সবচেয়ে সহজ ও আধুনিক)
1. `npm run build` চালান।
2. তৈরি হওয়া `dist/` ফোল্ডারের ভেতর `index.html` এবং `assets/` ফোল্ডারটি পাবেন।
3. **Website 2 APK Builder** বা **Capacitor** বা **Cordova**-তে এই `dist/` ফোল্ডারের ফাইলগুলো সিলেক্ট করে সরাসরি ১-ক্লিকে APK তৈরি করুন।

### পদ্ধতি ২: Android Studio WebView-তে সরাসরি ব্যবহার
1. Android Studio-তে একটি সাধারণ WebView প্রজেক্ট খুলুন।
2. প্রজেক্টের `app/src/main/assets/` ডিরেক্টরির ভেতর `dist/` ফোল্ডারের ভেতরের সমস্ত ফাইল পেস্ট করুন।
3. `MainActivity.java` বা `MainActivity.kt`-তে WebView সেটিংস এনাবল করে দিন:
   ```java
   myWebView.getSettings().setJavaScriptEnabled(true);
   myWebView.getSettings().setDomStorageEnabled(true);
   myWebView.loadUrl("file:///android_asset/index.html");
   ```
